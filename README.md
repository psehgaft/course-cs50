# course-cs50

Personal study archive of materials from Harvard's **CS50: Introduction to Computer Science** (Fall 2022) — lecture and section transcripts, CS50 Shorts transcripts, Lecture 0 slides, Scratch starter projects, and C example programs.

## Contents

| Path / file | Description |
| --- | --- |
| `2022_lecture0_720p_sdr-en.txt` – `2022_lecture2_720p_sdr-en.txt` | Full English transcripts of Fall 2022 lectures 0–2 |
| `2022_fall_section1-720p-en.txt`, `2022_fall_section2-720p-en.txt` | English transcripts of Fall 2022 sections 1–2 |
| `arrays-720p-en.txt`, `command_line-720p-en.txt`, `command_line_arguments-720p-en.txt`, `conditional_statements-720p-en.txt`, `data_types-720p-en.txt`, `functions-720p-en.txt`, `loops-720p-en.txt`, `operators-720p-en.txt`, `variables_and_scope-720p-en.txt` | English transcripts of the CS50 Shorts on core C topics |
| `guess-720p-en.txt`, `secret-720p-en.txt` | Shorts transcripts for the "Guess" and "Secret" examples |
| `add_two_numbers.txt` | C example: adding two integers with the CS50 library (`get_int`, functions) |
| `lecture0.pdf` | Lecture 0 slide deck |
| `src0/` | Scratch (`.sb3`) projects from Lecture 0: `hello`, `meow`, `pet`, `Oscartime`, `Raining Men`, `Ivy's Hardest Game`, and the Whack-A-Mole head exercise |

## Topics covered

- Computational thinking and Scratch (Lecture 0)
- C fundamentals: data types, operators, conditional statements, loops, and scope
- Functions and command-line arguments
- Arrays and the command line

## Usage

- **Read a transcript:** open any `.txt` file directly — transcripts are plain text, no tooling required.
- **Open a Scratch project:** import any `.sb3` file from `src0/` into the [Scratch editor](https://scratch.mit.edu/) (or open it offline in Scratch Desktop).
- **View the slides:** open `lecture0.pdf` in any PDF reader.
- **Try the C example:** `add_two_numbers.txt` contains a complete C program using the CS50 library. Save it as `adder-1.c` and compile it with the CS50 library installed:

  ```bash
  clang -o adder adder-1.c -lcs50
  ./adder
  ```
